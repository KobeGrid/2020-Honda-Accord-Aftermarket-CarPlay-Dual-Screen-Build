# 2020-Honda-Accord-Aftermarket-CarPlay-Dual-Screen-Build

A personal build log documenting the install of a standalone Apple CarPlay adapter screen into a 2020 Honda Accord that doesn't natively support CarPlay — resulting in a dual-screen setup with the factory display intact plus a dedicated second screen for CarPlay.

Overview
Vehicle: 2020 Honda Accord (no factory CarPlay support)
Goal: Add wireless/wired Apple CarPlay without touching or replacing the factory head unit
Result: Two-screen setup — factory infotainment untouched, plus a second display mounted off the passenger-side vent area running CarPlay (Maps, Messages, Contacts, Phone, Music, Siri)
Why a Second Screen Instead of Replacing the Head Unit

Swapping the factory head unit for a CarPlay-native one usually means losing climate controls, steering wheel integration, or factory vehicle settings that are tied to the OEM unit on many Honda models. A standalone adapter screen sidesteps that — the factory unit stays fully functional (climate readouts, fuel economy screen, Bluetooth pairing, etc. all untouched), and CarPlay runs independently alongside it.

What It Does

The adapter's home screen (see images/menu-screen.jpg) offers:

CarPlay — full Maps, Messages, Contacts, Phone, Music, Siri
Android Auto — same box supports both ecosystems
AirPlay / Miracast — screen mirroring
Audio Out / Bluetooth — audio routing options
Settings / Application — device config and app drawer

Boots with its own splash animation ("welcome you" — see images/boot-screen.jpg) independent of the Accord's factory startup.
